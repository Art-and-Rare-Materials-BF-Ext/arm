Created using SKOS Play

  • Biographical Note
    • DEF : A note about an individual or other agent, providing a narrative of the main life events, activities, functions, achievements, and/or roles of the agent being described.
  • Captions Note
    • DEF : A distinctive caption independent of the resource title, including mottos and headings.
  • Contents Note
    • DEF : A note to provide a main contents of the resource rather than linking to an external table of contents or creating separate part/whole relationships to the entities that comprise the whole. Ideally, part whole relationships would be created instead of the this type of note.
  • Descriptive Note
    • DEF : A note that describes the resource.
  • Historical Note
    • DEF : A note about an institution or corporate body providing a narrative of main events, activities, functions, achievements, and/or roles of the agent being described.
  • Imprint Note
    • DEF : A note providing details on publication, printing, or distribution of the resource being described.
  • Inaccuracy Note
    • DEF : A note explaining an unintentional or intentional inaccuracy, misspelling, or misprint relating to a specific resource.
  • Limitation Note
    • DEF : A note relating to the size and nature of a print run limited to a specific quantity of copies produced, or a statement relating to the enumeration and nature of a copy in relation to the larger print run.
  • Preferred Citation
    • DEF : A note providing a specific citation format for citing the resource.
  • Processing Note
    • DEF : A note that provides information about actions of the archivist, custodians, or creators of the entity being described.
  • Related Material Note
    • DEF : A note providing information on materials (e.g. archival materials or publications) related to the described resource. Use if information describing the related material cannot be parsed into the appropriate relationship.
  • Subject Note
    • DEF : Textual information describing the subject or iconographic details of a resource. Use for textual notes only; do not use for listing subject terms from controlled vocabularies.
  • Summary Note
    • DEF : A note providing a summary of the resource.
  • Supplementary Content Note
    • DEF : A note indicating the existence of supplementary content such as bibliographies, discographies, filmographies, and/or other bibliographic references in the described resource or in accompanying material.
