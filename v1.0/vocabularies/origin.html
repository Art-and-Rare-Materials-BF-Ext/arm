Art & Rare Materials BIBFRAME Ontology v1.0 - Origin Vocabulary

https://w3id.org/arm/vocabularies/1.0/origin/

Created using SKOS Play

  • added title page
    • DEF : Applies to a title appearing on a title page that has not been chosen as the chief source.
  • caption
    • DEF : Applies to a resource (e.g., a title) given at the beginning of the first page of the text.
  • container
    • DEF : Applies to a resource (e.g., a title) on the resource's container.
  • cover
    • DEF : Applies to a resource (e.g., a title) printed on the cover of a resource as issued.
  • margin
    • DEF : Applies to a resource printed on the top or bottom margin of each page of a publication (e.g., a running title).
  • spine
    • DEF : Applies to a resource found on the spine of a publication (e.g., a publisher's title).
  • supplied
    • DEF : Supplied value, not directly transcribed from the resource itself.
  • transcribed
    • DEF : Value transcribed directly from the resource.
  • translated
    • DEF : Value translated from another language, not transcribed from the resource itself.
